# EduBridge logo assets

The EduBridge wordmark uses a gold stroke to connect the lowercase **u** and uppercase **B**. All logo SVGs use editable outlines and require no fonts.

| Asset | Use |
| --- | --- |
| `edubridge-wordmark-for-light` (SVG, PNG) | Navy and amber on white or light backgrounds |
| `edubridge-wordmark-for-dark` (SVG, PNG) | Ivory and gold on navy or other dark backgrounds |
| `edubridge-wordmark-black` and `edubridge-wordmark-white` (SVG, PNG) | One-color layouts and print |
| `edubridge-app-icon` (SVG, PNG) | Square navy tile with the uB monogram; the PNG is 1024 × 1024 |
| `edubridge-favicon.ico` | Browser tab icon; includes 16, 32, and 48 px versions |
| `edubridge-logo-preview.png` | Reference sheet for choosing the right variant |

The wordmark PNGs are 2048 px wide with transparent backgrounds. Use SVG whenever possible for sharper scaling. For tight placements below about 140 px wide, use the monogram instead of shrinking the wordmark. Leave some breathing room around the logo and let the platform apply any app-icon corner mask.

Brand colors: midnight navy `#0C1730`, warm ivory `#FFF1D6`, gold on dark `#E4A238`, and amber on light `#A66612`.
