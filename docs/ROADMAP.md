# EduBridge AI Roadmap

## Phase 1: Foundation

- Finalize monorepo project structure.
- Scaffold FastAPI backend.
- Connect frontend to backend.
- Complete teacher, student, course, and enrollment flows.
- Keep SQLite for development.

## Phase 2: Document Upload

- Upload PDF, DOCX, and PPTX files.
- Store file metadata.
- Extract document text.
- Display uploaded materials in teacher dashboard.

## Phase 3: RAG Tutor

- Chunk extracted course content.
- Generate embeddings.
- Store embeddings in a vector database.
- Retrieve relevant chunks for student questions.
- Generate source-grounded answers with citations.

## Phase 4: Misconception Detection

- Analyze student explanations.
- Detect missing concepts.
- Identify misconception categories.
- Generate student feedback and teacher notes.

## Phase 5: Adaptive Quiz Engine

- Generate quizzes from course material.
- Track answers and attempts.
- Adjust topic focus based on weak areas.
- Update progress automatically.

## Phase 6: Teacher Analytics

- Build class insight reports.
- Show per-student weakness summaries.
- Show common misconception maps.
- Generate AI teaching recommendations.

## Phase 7: Final Polish

- Add authentication and role-based authorization.
- Prepare deployment.
- Write final documentation.
- Create presentation slides.
- Prepare demo script and evaluation results.
