# Reporting a security issue

Use [GitHub's private vulnerability reporting form](https://github.com/Shaadi619/edubridge-ai/security/advisories/new). Include the affected feature and revision, the expected behavior, and the impact. Use fictional records when describing a problem.

Do not post credentials, student identifiers, course materials, private URLs or sensitive logs in a public issue or pull request. If a credential was published, revoke or rotate it at its provider first; removing the file from Git does not invalidate the credential.
