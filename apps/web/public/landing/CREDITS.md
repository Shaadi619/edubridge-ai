# EduBridge landing assets

- **chalkboard.webp** — a frame from Vitaly Gariev’s classroom footage, [Teacher writing mathematical formulas on a blackboard](https://unsplash.com/photos/teacher-writing-mathematical-formulas-on-a-blackboard-NpHSRakEYPM), distributed under the [Unsplash License](https://unsplash.com/license). Used as an editorial image, not a photograph of an EduBridge user or a particular university. The homepage also credits the photographer.
- **show-your-work.webp** and **teacher-today.webp** — existing EduBridge course screenshots. The student’s name is changed. They are not mockups.
- **Newsreader** — roman and italic Latin WOFF2 subsets served locally, sourced from Fontsource. See the bundled Newsreader-LICENSE.txt (SIL Open Font License). This font license applies to the typeface, not the EduBridge repository.
